# e2e_competition：九类转向角分类改造说明

本文档说明在保留原 `e2e_self-driving/Net` 整体设计（数据管线、图像预处理、训练与 ONNX 流程）的前提下，将**回归输出单标量转向角**改为**九类离散分类**的改动。新代码位于目录 **`e2e_competition/Net`**，不修改原仓库中的 `e2e_self-driving`。

## 九类档位定义

物理含义与原回归任务一致，仅将连续角离散为下列九个值（顺序即类别索引 `0`～`8`）：

| 类别索引 | 转向角 |
|---------|--------|
| 0 | 1.72 |
| 1 | 1.64 |
| 2 | 1.5 |
| 3 | 0.0 |
| 4 | -1.5 |
| 5 | -1.56 |
| 6 | -1.58 |
| 7 | -1.6 |
| 8 | -1.62 |

任意标注中的浮点角在 **`create_data_lists.py`** 与 **`datasets.py`** 中均通过**最近邻**映射到上述某一档。

## 新增文件

| 文件 | 作用 |
|------|------|
| `Net/steering_config.py` | 集中定义 `STEERING_CLASSES`、`NUM_CLASSES`，以及 `angle_to_class` / `class_to_angle` |
| `Net/test.py` | 单张图像测试：对比**原始真值角**与**模型九档推理角**，输出绝对偏差与偏差率（相对真值绝对值） |

## 修改对照（相对原 `e2e_self-driving/Net`）

### `models.py`

- 最后一层由输出 **1 维标量**改为输出 **`NUM_CLASSES`（9）维 logits**。
- `forward` 返回值形状为 `(N, 9)`，不再为 `(N, 1)`。

### `datasets.py`

- 从 `train.txt` / `val.txt` 读取路径与浮点角后，用 `angle_to_class` 转为 **long 型类别索引**。
- 返回标签为 `torch.long` 的一维标量张量，供 `CrossEntropyLoss` 使用。
- 空行判断由 `strip() is None` 改为 `not file.strip()`（原写法在 Python 中恒为假）。

### `train.py`

- 损失函数由 **`MSELoss`** 改为 **`CrossEntropyLoss`**。
- TensorBoard：`MSE_Loss` 改为 **`CE_Loss`**，并增加 **`Train_Acc`**（batch 分类准确率）。
- 其余结构（数据路径、`DataLoader`、`Adam`、`ve2.pth` 保存方式等）与原项目一致。

### `create_data_lists.py`

- 从文件名解析原始浮点角后，先 **`angle_to_class`** 再 **`class_to_angle`**，将列表中的角度**写为九类标准值之一**，保证列表文件与分类标签一致。

### `export_onnx.py`

- 默认加载 **`ve2.pth`**（与当前 `train.py` 保存名一致，原项目 `export_onnx` 使用 `ve.pth`，此处按竞赛目录内训练脚本对齐）。
- 导出 ONNX 的 **`output` 为 9 维 logits**；部署时需 **`argmax`** 再查表得到转向角（见 `onnx_inference.py`）。

### `onnx_inference.py`

- 在 ONNX 输出上执行 **`argmax`**，用 **`class_to_angle`** 打印对应的离散转向角，并提示档位表。

### `utils.py`

- 与原版一致；注释中“精度”泛指指标，分类训练下可用于准确率等。

### `onnx_simplified.py`

- 逻辑与原版相同，仅保留与 `e2e_competition/Net` 下路径一致的说明性输出。

### `test.py`

- 单图 PyTorch 推理，预处理与 `datasets.py` / `train.py` 一致（BGR→HSV、`Resize(120,160)`、`ToTensor`）。
- **真值**：文件名末段或 `--angle` 给出的**连续浮点角**，**不再**先做九档最近邻；与训练列表中的离散标签可以不一致，便于反映标注噪声。
- **推理**：`argmax` + `class_to_angle` 得到九档上的预测角。
- **绝对偏差**：`|推理角 - 真值角|`。
- **偏差率**：`绝对偏差 / |真值| × 100%`（相对真值幅度的百分比）。若真值为 `0`，分母无定义，脚本会提示「未定义」。
- 用法示例：`python test.py path/to/xxx_0.0.jpg`，或 `python test.py some.jpg --angle 0.0 -c ve2.pth`。

## 使用说明（与原项目对齐）

1. 在 `e2e_competition/Net` 下运行 **`create_data_lists.py`** 生成 `train.txt` / `val.txt`（角度已量化到九档）。
2. 配置 `train.py` 中 `data_folder` 指向含上述 txt 的数据目录后训练，得到 **`ve2.pth`**。
3. 使用 **`export_onnx.py`** 导出 ONNX；推理时对输出做 **argmax**，再用 **`steering_config.STEERING_CLASSES`** 或 **`class_to_angle`** 还原转向角语义。
4. 使用 **`test.py`** 对单张图对比真值与预测转向角（需已有 `ve2.pth` 或 `-c` 指定权重）。

## 注意事项

- **旧回归权重**与新版分类头形状不兼容，不能直接加载到最后一层；需重新训练或仅做部分层迁移（本目录未实现部分加载逻辑）。
- 若部署链路与原 ONNX 文件名不同，请自行修改 `onnx_inference.py` 中的 `onnx_path`。

## 新增：Net_improve（抗过拟合版本）

针对“单地图、室内、轨迹重合率高”的小样本场景，已新增目录 `e2e_competition/Net_improve`，核心目标是降低过拟合风险：

- 更轻量网络结构（深度可分离卷积 + 全局池化）；
- 更强训练约束（数据增强、AdamW、label smoothing、验证集监控、早停）；
- 输出权重：`ve2_improve.pth` 与 `ve2_improve_best.pth`。

详细说明见：`e2e_competition/Net_improve/改进说明.md`。
