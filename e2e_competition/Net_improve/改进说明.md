# Net_improve 改进说明（针对小数据、高重合率场景）

## 1. 过拟合原因分析

你当前场景是「单张竞赛地图 + 室内 + 轨迹重合率高」，数据分布非常集中。  
在这种条件下，模型很容易记住背景纹理与固定路径细节，而不是学习可泛化的“转向语义”。

原 `Net` 的主要问题：

- 全连接层输入为 `64*8*13=6656`，后接 `100/50/10`，参数量主要集中在全连接层；
- 训练脚本仅有 `Resize + ToTensor`，增强强度不足，等价样本太少；
- 仅训练集损失监控，没有验证集约束与早停机制；
- 优化器无显式权重衰减，容易把噪声特征也拟合进去。

结论：**参数量偏大是重要原因之一，但不是唯一原因**。  
在你这种数据条件下，通常是「模型容量 + 弱增强 + 训练约束不足」共同导致过拟合。

## 2. Net_improve 的核心改动

### 2.1 结构改动（`models.py`）

- 使用深度可分离卷积块（Depthwise + Pointwise）替代重型卷积；
- 使用 `AdaptiveAvgPool2d(1)` 代替大尺寸展平，显著减少全连接参数；
- 增加 `BatchNorm` 和分层 `Dropout`；
- 头部改为 `64 -> 32 -> NUM_CLASSES` 的轻量分类器。

这使模型更轻、更不容易记忆训练集噪声。

### 2.2 训练改动（`train.py`）

- 训练增强：
  - `ColorJitter`
  - `RandomAffine`（小幅旋转/平移/缩放）
- 损失：`CrossEntropyLoss(label_smoothing=0.05)`
- 优化器：`AdamW(weight_decay=1e-4)`
- 学习率调度：`ReduceLROnPlateau`（由验证损失驱动）
- 增加 `EMA`（参数指数滑动平均，默认 `decay=0.999`）
- 训练稳定性：梯度裁剪 `clip_grad_norm_`
- 泛化约束：
  - 由原始 `train.txt + val.txt` 合并后，自动做 `train/val/test` 三划分（默认 `70/15/15`）
  - 训练集使用 `WeightedRandomSampler` 缓解类别不均衡
  - 增加验证集评估（`val loss / val acc`）
  - 最优模型保存（`ve2_improve_best.pth`）
  - 早停（默认 `patience=12`）
  - 训练结束后自动加载最优模型并汇报 `test loss / test acc`

EMA 的使用方式：

- 训练时每步 `optimizer.step()` 后更新 EMA 参数；
- 验证、早停判断与模型保存都基于 EMA 权重；
- 推理部署直接加载保存好的权重，不引入额外推理分支，**不会增加端侧时延**。

## 3. 文件说明

- `steering_config.py`：九类转向角配置与映射；
- `models.py`：改进后的网络结构；
- `train.py`：改进后的训练策略（含验证与早停）。

## 4. 使用方式

在 `e2e_competition/Net_improve` 目录运行：

```bash
python train.py
```

默认读取 `data/simulate/data/train.txt` 与 `val.txt`。  
输出：

- 最新权重：`ve2_improve.pth`
- 最优权重：`ve2_improve_best.pth`
- 终端额外输出：最优模型在 test 集上的 `TestLoss/TestAcc`

## 5. 进一步建议（可选）

- 若类别分布不均，给 `CrossEntropyLoss` 加 class weight；
- 可尝试 MixUp/CutMix（小概率）进一步抑制记忆化；
- 评估时重点观察 `train acc - val acc` 差距，而不仅仅是训练损失。
